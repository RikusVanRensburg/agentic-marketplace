# defending-findings

A finding is guilty until proven innocent. Before a claim that was worked out, not read off the
screen, is acted on, cited or summarized, it gets defended: the case for it, an honest attack on
it, and the evidence that survives. The calibration decides whether it stands.

## Install

```
/plugin marketplace add RikusVanRensburg/agentic-marketplace
/plugin install defending-findings@agentic-marketplace
```

## Skills

| Skill | Use it to |
|---|---|
| `defending-findings` | Defend a finding before acting on it: a cause, a state of the code, a synthesis, a recommendation, or a claim that something is correct |
